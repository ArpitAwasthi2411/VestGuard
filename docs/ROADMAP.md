# Roadmap

| Stage | Work |
|---|---|
| **V3 electronics** | LTE Cat-1 (A7672S) — SMS and voice calls from the vest itself, GNSS; module powered only when needed |
| **Wearability** | Removable spine strip and sealed pod, magnetic charging, washable vest; designs for men, women and summer |
| **Sensing** | Additional sensing to further reduce false alarms |
| **Intelligence** | Multi-person dataset; trained model running on the vest |
| **Wellbeing** | No-movement alert, daily activity, walking-steadiness trend |
| **Pilot** | Supervised pilot with one primary health centre and its ASHA workers |
| **Product** | Custom PCB, certification path, complete patent specification |
