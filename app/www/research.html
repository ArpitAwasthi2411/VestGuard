Hardware checklist
    Tests

    Calibrate upright: wearer puts the vest on and stands straight and still. This records which way is "up" for each sensor, so the exact board orientation doesn't need to be known. Redo it for every new wearer or after re-mounting.
    Still test: vest lying still on a table. Tap test: flick only the named sensor — confirms they aren't swapped.

    Orientation

    Up axis = the board axis that points up when the wearer stands (from calibration). Tilt = how far the trunk has leaned from that upright pose (0° standing, ~90° lying). Gravity now = which axis currently carries gravity. Since both boards are mounted the same way, both should show the same up axis.
